# Matrix Discord Bot

بوت ديسكورد عربي متكامل + Dashboard.

## Installation

    git clone <repo>
    cd matrix-bot-node
    npm install
    cp .env.example .env
    # edit .env
    npm start

## Features

- Moderation (ban, kick, mute, jail, warn)
- Temp punishments
- Roles management
- Logging
- Welcome + Autorole
- Custom commands & aliases
- Auto responder
- AFK
- REST API for Dashboard
